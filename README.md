# Из одного сердца

Живая открытка: [vidalost.github.io/Stix](https://vidalost.github.io/Stix/).

На светло-бежевой бумаге пульсирует маленькое сердце с надписью «Нажми».
После касания появляется линия земли, сердце падает с ускорением, дважды слегка отскакивает и становится семенем.
Из того же места постепенно вырастает дерево: изогнутый ствол с фактурой коры, сужающиеся ветви и тонкие побеги.
На дереве раскрываются красные и розовые листья-сердечки. Крона складывается в большое сердце; отдельные листья подхватывает лёгкий ветер, они медленно опускаются на землю.

## Управление

Коснитесь сердца, чтобы открыть открытку. После раскрытия дерева в нижнем правом углу доступны пауза и повтор.
Пробел ставит анимацию на паузу, Escape приостанавливает её. Кнопки доступны с клавиатуры и имеют подписи для экранного диктора.
При системной настройке уменьшения движения касание сразу открывает неподвижное выросшее дерево.
Скрытая вкладка приостанавливает анимацию; возвращение продолжает её с того же места.

## Запуск и публикация

Требуется Node.js 22 или новее. Зависимостей, внешних шрифтов, изображений, трекеров и сервера нет.

```sh
npm run check
npm test
npm run build
```

Готовый сайт находится в `dist/`. Все пути относительные, включая публикацию в `/Stix/`.
Существующий workflow `.github/workflows/pages.yml` автоматически проверяет, собирает и публикует главную ветку в GitHub Pages.

## Анимация

- `assets/tree-model.js` — свободное падение, затухающие отскоки, непрерывная геометрия дерева, листва и движение с сопротивлением воздуха.
- `assets/tree-scene.js` — Canvas 2D, фактура коры, поэтапный рост, раскрытие листьев, ветер и опадание.
- `assets/tree-app.js` — касание, пауза, повтор, размеры экрана, скрытие вкладки и уменьшенное движение.
- `assets/tree.css` — светлая бумага и пульсация начального сердца.

Ветви соединяются с фактическими точками кривых родительских ветвей и появляются только после того, как ствол дорастает до места развилки.
Гравитация рассчитывается по времени, поэтому пропущенный кадр не меняет траекторию. Листья замедляются сопротивлением воздуха, покачиваются, останавливаются на земле и постепенно исчезают.
Одновременно опадает не более 26 листьев. Ствол и крона рисуются в отдельных буферах; плотность пикселей ограничена для телефона.

Тесты проверяют ускорение и отскоки, соединение и сужение ветвей, порядок появления листьев, остановку опавшей листвы и размещение дерева на узких и широких экранах.
