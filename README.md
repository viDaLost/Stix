# Самый тихий свет

Самостоятельная символьная экранизация предоставленного автором стихотворения. Сайт: **https://vidalost.github.io/Stix/**. Исходный проект Love не изменяется.

## Замысел

Стих движется от неуловимого образа через расстояние к возможности общей жизни. Свет связывает три строфы: сначала он указывает путь, затем становится сбережённым дыханием, в финале освещает встречу. Текст сохранён дословно, включая «вёрсты», «намёков», тире и пунктуацию.

| Время | Строки и иллюстрация | Музыка |
| --- | --- | --- |
| 0–34 с | Арки сна, отражения на воде, едва различимый силуэт и путь света | Редкие стеклянные ноты, открытые минорные созвучия |
| 34–68 с | Разделённые берега, тонкая связь; ладони сохраняют дышащий свет | Мягкие задержания, близкое тёплое звучание |
| 68–101 с | Рассвет, сближение силуэтов, растущие ветви и раскрывающиеся цветы | Светлые созвучия и более частые переливы |
| 101–108 с | Лепестки возвращаются к ночной пыли, вновь проявляются арки | Возврат к первому созвучию |

Строки проявляются последовательно, без печатания по буквам; вся строфа остаётся для чтения. Последняя строка каждой строфы полностью видна около 8–10 секунд. Цикл — 108 секунд. Изображение построено из оригинальной проецируемой геометрии и окрашенных символов; фотографии, видеозаписи и портреты не используются. Перспектива, туман, отражения и разные планы дают глубину.

## Управление

Музыка запускается только кнопкой **«Включи музыку»**. × скрывает кнопку; касание иллюстрации возвращает её. **M** — музыка, **пробел** — пауза, **Enter** — начало. Клавиши на самой кнопке сохраняют обычное поведение браузера.

Пауза или скрытие вкладки останавливают ход истории и звук. При системной настройке уменьшения движения показаны неподвижная иллюстрация и весь стих. Без JavaScript текст также доступен целиком. Для экранного диктора все 12 строк присутствуют в обычном HTML.

Музыка — оригинальная процедурная партитура на Web Audio: мягкие синусоидальные тембры, короткие колокольные обертоны, стереопанорама и реверберация. Внешние треки, аналитика, библиотеки и сетевые запросы для воспроизведения не нужны.

## Проверка и публикация

Требуется Node.js 22 или новее, установка зависимостей не нужна:

```sh
npm run check
npm test
npm run build
```

`dist/` содержит готовый статический сайт. В GitHub Settings → Pages необходимо выбрать **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет текст, JavaScript, тайминг и жизненный цикл звука, затем публикует `dist/`. Все пути относительные, сайт работает в `/Stix/`.

`assets/story.js` хранит точный текст и тайминг, `renderer.js` — символьные иллюстрации, `music.js` — партитуру, `app.js` — взаимодействия и общий ход времени. Ограничение частоты 30 кадров/с, сетки символов и плотности пикселей снижает нагрузку на телефон. Для локального просмотра готовый `dist/` можно открыть через любой статический HTTP-сервер.

Проверки аудиографа не заменяют прослушивание на конкретном устройстве: громкость зависит от браузера и динамиков. Визуальный язык символьный, поэтому рисунки намеренно условны.
